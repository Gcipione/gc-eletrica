# GC Elétrica

Site/vitrine da GC Elétrica (React + Vite + Tailwind) com dados no Supabase.

## Rodar localmente
1. `npm install`
2. Copie `.env.example` para `.env.local` (variáveis `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY`)
3. `npm run dev`

## Deploy
Vercel (Vite). Defina as mesmas variáveis `VITE_SUPABASE_*` no projeto.
